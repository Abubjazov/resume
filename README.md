# Радик Абубязов — Product Manager

Статическое портфолио на русском языке. HTML, CSS и JavaScript без сборки и внешних зависимостей. Шрифты и резюме хранятся локально.

## Локальный запуск

Из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173.

## Структура

- `index.html` — содержание и семантическая разметка.
- `styles.css` — адаптивный дизайн, шрифты, анимации и reduced-motion.
- `script.js` — появление секций и копирование email.
- `assets/` — локальные шрифты и последняя согласованная версия PDF.

Кейсы раскрываются нативными элементами details/summary, включая управление с клавиатуры. Контент доступен без JavaScript. Все пути относительные для совместимости с проектным URL GitHub Pages.
